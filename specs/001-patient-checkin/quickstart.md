# Quickstart: Patient Check-In (Phone)

## Prerequisites
- Python 3.12

## Install dependencies

```bash
uv pip install flet pytest
# or
python -m pip install flet pytest
```

## Run (placeholder app)

```bash
python main.py
```

## Test (to be added)

```bash
pytest -q
```

## Notes
- No database in MVP; in-memory mock store only.
- UI aims to be responsive for iPad/iPhone sizes.
- Logs must not include PII; mask phones (e.g., ***1234).
